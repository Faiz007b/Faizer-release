# Faizer — Android Wi-Fi Scanner

Faizer is an Android application designed to scan for compatible Wi-Fi networks and display supported network information.

## Features
- Scan for nearby Wi-Fi networks.
- Identify networks matching supported naming patterns.
- Simple Android interface.
- Licence-based access.

## Requirements
- Compatible Android device with Wi-Fi.
- Required Android permissions.
- Internet connection for online licence validation, where required.

## Installation
1. Download the APK from the official Releases section.
2. Review the installation instructions.
3. Install the app and follow the in-app activation steps.

## Licence
Faizer offers a lifetime licence subject to its published terms. Check the licence conditions for device restrictions, updates, and online-service availability before purchasing.

## Privacy and Security
Only use the app to test networks you own or have permission to access. Review the app's permissions and privacy information before installation.
